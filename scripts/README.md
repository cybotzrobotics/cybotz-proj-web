# Scripts

This folder contains utility scripts for testing and debugging the Cybotz project.

## Testing Scripts
- `test_*.js` - Various database and functionality tests
- `debug_*.js` - Debugging utilities

## Utility Scripts
- `apply_fix.js` - General fixes
- `fix_questions.js` - Question data fixes

## Usage

Run these scripts with Node.js:
```bash
node scripts/script_name.js
```

Make sure to set up your environment variables before running any database-related scripts.
