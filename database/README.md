# Database Scripts

This folder contains all SQL scripts for the Cybotz project database setup and management.

## File Organization

### Setup Scripts
- `database_setup_complete.sql` - Complete database setup
- `database_schema_fix.sql` - Schema corrections
- `database_table_structure.sql` - Table definitions

### Feature Scripts
- `database_elo_system.sql` - ELO rating system
- `database_leaderboard_setup.sql` - Leaderboard functionality
- `database_daily_ranked_setup.sql` - Daily ranking system
- `database_profile_fix.sql` - User profile management

### Utility Scripts
- `database_permissions_fix.sql` - Permission corrections
- `database_rls.sql` - Row Level Security
- `database_functions_only.sql` - Database functions

### Test Scripts
- `database_function_test.sql` - Function testing
- `database_check.sql` - Database validation

## Usage

Run these scripts in your Supabase SQL editor or preferred database management tool.
